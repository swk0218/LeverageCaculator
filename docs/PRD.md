# Product Requirements

양복음복 is a no-login, mobile-first calculator for Korean listed leveraged and inverse ETF/ETN holders. A user selects a verified product, enters the purchase date, purchase price, and quantity for each currently held lot, then sees actual P/L, the product return needed to break even, equal-daily-move underlying break-even scenarios, compounding effect, and the gap between daily theory and actual product performance.

Position inputs remain in the browser. Official market data is fetched by product code and date range only. The service is an educational calculation tool, not investment advice or a forecast.
